## 📌 Overview

A web implementation of the viral word puzzle game **Wordle**. Players have 6 chances to guess a secret 5-letter word, with dynamic color feedback indicating letter accuracy.

---

## ✨ Key Features

- **Official Color Feedback System:** Green (Correct spot), Yellow (Wrong spot), and Gray (Not in word).
- **Interactive On-Screen & Physical Keyboard:** Seamless input handling supporting both physical keyboard typing and on-screen button taps.
- **Flip & Bounce Animations:** CSS flip animations on word submission and shake animations on invalid entries.
- **Game State Engine:** Tracks win streaks, game completion, and prevents further input upon game conclusion.

---

## 💻 Tech Stack & Architecture

- **Game Engine:** Vanilla JavaScript Game State Logic
- **Styling & UI:** CSS3 Grid, 3D Card Flip Transforms, Responsive Mobile Layout
